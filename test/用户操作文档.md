## 一、系统概述

UAMS（Unified Authentication Management System）是一个统一认证管理系统，兼具企业网盘功能。主要模块：

| 模块 | 功能 |
|------|------|
| 工作台 | 首页仪表盘，数据概览 |
| 系统管理 | 管理员用户/角色/菜单管理 |
| 统一认证 | 自然人/企业用户管理，多种登录方式 |
| 文件管理 | 个人文件上传/下载/目录管理 |
| 团队管理 | 创建团队、邀请成员、团队文件 |
| 文件分享 | 生成分享链接、密码保护 |
| 系统监控 | 在线用户、服务器状态 |
| AI助手 | 右下角智能对话 |

## 二、登录系统

### 2.1 打开系统
浏览器访问: `http://localhost:5173`

### 2.2 管理员登录
- 用户名: `admin`
- 密码: `123456`
- 点击「管理员登录」

### 2.3 其他登录方式
系统支持4种登录方式：
1. **密码登录**: 手机号 + 密码（自然人用户）
2. **短信登录**: 手机号 + 验证码
3. **企业登录**: 两步验证（先查企业再登录）
4. **OAuth2**: 第三方应用授权

### 2.4 登录后界面
登录成功后进入工作台首页，左侧为导航菜单，右上角显示用户头像和快捷操作。

<a name="3"></a>
## 三、系统管理

> 仅管理员角色可操作

### 3.1 用户管理
路径: `系统管理 → 用户管理`

| 操作 | 说明 |
|------|------|
| 查询 | 支持按用户名、状态筛选，分页展示 |
| 新增 | 填写用户名、密码、昵称等信息 |
| 修改 | 修改用户基本信息 |
| 删除 | 逻辑删除，数据保留 |
| 分配角色 | 为用户绑定系统角色 |

### 3.2 角色管理
路径: `系统管理 → 角色管理`

- 系统预置 4 种角色: 超级管理员、系统管理员、审计员、普通用户
- 支持新增自定义角色
- 为角色分配菜单权限

### 3.3 菜单管理
路径: `系统管理 → 菜单管理`

- 树形结构展示所有菜单
- 支持新增/修改/删除菜单
- 菜单类型: 目录(M)、菜单(C)、按钮(F)

## 四、文件管理

### 4.1 进入文件管理
方式1: 点击左侧菜单「文件管理」
方式2: 工作台点击「进入个人文件库」

### 4.2 基础操作

| 操作 | 方式 |
|------|------|
| **上传文件** | 点击「上传」按钮，选择本地文件 |
| **批量上传** | 支持多文件同时上传 |
| **新建目录** | 点击「新建文件夹」，输入名称 |
| **下载文件** | 点击文件行的「下载」按钮 |
| **重命名** | 点击「重命名」，修改文件/目录名 |
| **移动** | 勾选文件，点击「移动到」，选择目标目录 |
| **复制** | 勾选文件，点击「复制到」，选择目标目录 |
| **删除** | 勾选文件，点击「删除」（逻辑删除） |

### 4.3 文件特性
- **秒传**: 文件 MD5 已存在时直接关联，无需重复上传
- **版本管理**: 支持文件版本记录
- **标签**: 为文件添加标签，方便分类检索
- **搜索**: 支持按文件名、扩展名筛选

### 4.4 目录树
左侧目录树展示用户的完整目录结构，支持展开/折叠，点击目录查看对应文件。

<a name="5"></a>
## 五、团队协作

### 5.1 创建团队
1. 点击「团队管理」菜单
2. 点击「创建团队」
3. 填写团队名称、最大成员数
4. 确认创建

### 5.2 管理成员

| 操作 | 说明 |
|------|------|
| 邀请成员 | 输入用户信息，发送邀请 |
| 移除成员 | 将成员移出团队 |
| 角色设置 | creator(创建者)、admin(管理员)、member(成员)、guest(访客) |

### 5.3 团队文件
- 每个团队自动分配专属文件夹
- 支持设置文件权限: read(读取)、download(下载)、edit(编辑)、manage(管理)
- 只有创建者可以解散团队

<a name="6"></a>
## 六、文件分享

### 6.1 创建分享
1. 在文件列表中选择文件
2. 点击「分享」
3. 设置分享参数:
   - **访问密码**: 可选，为空则不校验
   - **过期时间**: 可选，到时间自动失效
4. 确认后生成分享码

### 6.2 访问分享
- 访客打开分享链接，输入分享码
- 如设置了密码，需输入正确密码
- 验证通过后可查看/下载文件

### 6.3 管理分享
- 「我的分享」可查看所有分享记录
- 支持取消分享（删除分享记录）

<a name="8"></a>
## 八、常见问题 FAQ

### Q1: 忘记管理员密码怎么办？
联系 DBA 在数据库 `sys_user` 表中重置密码（BCrypt 加密）。

### Q2: 上传文件大小有限制吗？
默认最大 500MB，可在 `application.yml` 中修改 `dfs.storage.local.max-size`。

### Q3: 文件存储在哪里？
存储于 MinIO 对象存储（`uams-files` bucket），也可切换为本地存储。

### Q4: 如何添加新用户？
管理员登录 → 系统管理 → 用户管理 → 新增用户。

### Q5: 删除的文件能恢复吗？
系统使用逻辑删除（del_flag），数据保留在数据库中，可联系管理员恢复。

### Q6: 短信验证码登录为什么不能用？
需要安装并启动 RabbitMQ 服务，短信异步发送依赖消息队列。

### Q7: 团队权限怎么划分？
4个级别: creator(所有权限) > admin(管理成员文件) > member(读写文件) > guest(仅读)

### Q8: 浏览器兼容性？
推荐使用 Chrome、Edge、Firefox 最新版本。
