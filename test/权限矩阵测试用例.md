# UAMS 权限矩阵测试用例

**版本**: v1.0 | **日期**: 2026-06-12

---

## 一、角色定义

| 角色标识 | 角色名 | 权限说明 |
|----------|--------|----------|
| SUPER_ADMIN | 超级管理员 | 全部权限 |
| SYSTEM_ADMIN | 系统管理员 | 系统管理权限 |
| AUDITOR | 审计员 | 查看操作日志 |
| USER | 普通用户 | 基础权限 |

> 当前 `getPermissionList` 返回空列表，仅做登录拦截 + 角色身份校验，无细粒度按钮级权限。

---

## 二、权限拦截路径

以下路径受 Sa-Token 拦截保护（需登录）：
```
/api/system/**, /api/uas/**, /api/dashboard/**, /api/monitor/**,
/api/tool/**, /api/file/**, /api/folder/**, /api/share/**
```

白名单（无需登录）：
```
/api/system/login, /api/uas/auth/**, /api/share/access/**
```
