# 项目交接文档 (Handover Documentation)

欢迎接手本项目！本文档旨在帮助你快速了解本项目的环境配置、运行方式以及测试方法。

## 1. 技术栈与运行环境

本项目为前后端分离架构，主要使用了以下技术栈和中间件环境：

### 后端架构
- **语言框架**: Java 17, Spring Boot 3.x
- **数据访问**: MyBatis-Plus
- **权限管理**: Sa-Token
- **构建工具**: Maven

### 前端架构
- **核心框架**: Vue 3 (Composition API)
- **构建工具**: Vite
- **UI 组件库**: Element Plus
- **状态管理 & 路由**: Pinia, Vue Router

### 依赖中间件
本项目依赖多个中间件提供数据持久化、缓存、消息队列和对象存储服务：
- **MySQL (3306)**: 核心关系型数据库。
- **Redis (6379)**: 用于缓存和 Session 存储。
- **RabbitMQ (5672/15672)**: 消息队列（未来用于异步处理）。
- **MinIO (9000/9001)**: 本地对象存储服务，用于文件管理和团队资料上传。

## 2. 环境搭建与项目启动

### 2.1 启动基础设施 (中间件)
为了方便快速启动，项目根目录下提供了 `docker-compose.yml`，包含了 MinIO、Redis 和 RabbitMQ 的容器配置：
```bash
# 在项目根目录下运行
docker-compose up -d
```
> **注**: MySQL 需要单独运行，或在本地准备好 MySQL 服务。

### 2.2 数据库初始化
在启动后端之前，请先初始化 MySQL 数据库：
1. 创建数据库（如 `uams` 或对应你在 `application-dev.yml` 中配置的库名）。
2. 执行项目提供的 SQL 脚本以初始化表结构和基础数据：
   - `sql/init.sql` (基础系统表)
   - `sql/init_dfs.sql` (文件系统及团队相关表)

### 2.3 启动后端服务
1. 进入后端代码目录 `backend`。
2. 确保你的 JDK 环境变量为 **Java 17**。
3. 修改 `src/main/resources/application-dev.yml` 中的 MySQL 密码和用户名（如果与你的本地环境不一致）。
4. 使用 Maven 启动：
```bash
mvn clean install -DskipTests
mvn spring-boot:run
```
后端服务默认将在 `http://localhost:8080` 启动。

### 2.4 启动前端服务
1. 进入前端代码目录 `frontend`。
2. 确保你的 Node.js 环境在 v16 或更高版本。
3. 安装依赖并启动：
```bash
npm install
npm run dev
```
前端服务默认将在 `http://localhost:5173` 启动，并在内部自动将 `/api` 请求代理到后端的 8080 端口。

## 3. 测试数据与验证方法

### 3.1 预设测试账号
数据库初始化后，会自动写入系统默认超级管理员账号供测试使用：
- **账号**: `admin`
- **密码**: `123456` (原文档误写为 admin123，已修正)

### 3.2 验证方法与主要模块
在浏览器打开前端地址（`http://localhost:5173`）并使用上述账号登录后，你可以对以下核心模块进行测试：

1. **工作台与菜单跳转 (Dashboard)**
   - 检查登录后能否正常进入 Dashboard 主页。
   - 检查卡片上的“进入个人文件库”和“进入团队空间”等快捷按钮能否成功实现路由跳转。
2. **文件系统 (DFS Module)**
   - 进入文件模块，测试新建文件夹、文件夹重命名等基础操作（文件上传的具体 MinIO 链路还在对接中，为 TODO 项）。
3. **团队管理 (Team Module)**
   - 进入团队空间，测试创建新团队。
   - 观察新团队创建后，是否会在文件系统中自动分配专属的团队文件夹。
4. **AI 智能助手 (AI Module)**
   - 点击右下角的 AI 悬浮球，调出聊天弹窗。
   - 发送任意文本，验证前后端的聊天接口链路是否通畅（当前后端 `AIController` 返回模拟 Mock 数据）。

### 3.3 遗留问题与 TODO 列表
接手后可优先关注以下待完善部分：
- **真实 AI 接入**: 将 `AIService` 中的模拟返回替换为真实的大模型（如智谱、通义千问等）SDK 调用。
- **文件上传打通**: 完善 `TeamFileController` 的接收逻辑，彻底将二进制文件流对接到 Docker 中的 MinIO 服务。
- **毛玻璃 UI 美化**: 目前部分弹窗组件缺乏层次感，需在 `glass.css` 或组件内部增强 CSS 的微交互和磨砂透明特效。
