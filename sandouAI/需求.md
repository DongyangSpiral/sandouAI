# UAMS 统一认证管理系统 —— 需求文档

## 项目定位

UAMS（Unified Authentication Management System）是一个统一认证管理系统，后扩展为包含文件管理与团队协作的企业网盘平台。

---

## 一、系统管理模块

### 1. 管理员用户管理 `/system/user`

| 功能 | 说明 |
|------|------|
| 分页查询 | GET `/api/system/user/list`，支持用户名、状态筛选 |
| 新增 | POST `/api/system/user`，密码 BCrypt 加密 |
| 修改 | PUT `/api/system/user` |
| 删除 | DELETE `/api/system/user/{id}`，逻辑删除 |
| 详情 | GET `/api/system/user/{id}` |
| 分配角色 | POST `/api/system/user/assignRoles` |

### 2. 角色管理 `/system/role`

| 功能 | 说明 |
|------|------|
| 分页查询 | GET `/api/system/role/list` |
| 全部角色 | GET `/api/system/role/all` |
| 新增/修改/删除 | POST/PUT/DELETE `/api/system/role` |
| 分配菜单权限 | POST `/api/system/role/assignMenus` |

### 3. 菜单管理 `/system/menu`

| 功能 | 说明 |
|------|------|
| 菜单树 | GET `/api/system/menu/tree`，递归父子结构 |
| 全部列表 | GET `/api/system/menu/list` |
| 新增/修改/删除 | POST/PUT/DELETE `/api/system/menu` |

### 4. 扩展管理（SystemExtend）

- 部门管理 `/system/dept/*`
- 岗位管理 `/system/post/*`
- 字典管理 `/system/dict/type/*`, `/system/dict/data/*`
- 参数配置 `/system/config/*`
- 通知公告 `/system/notice/*`
- 操作日志 `/system/operlog/*`

## 二、统一认证模块（UAS）

### 1. 自然人用户 `/uas/user`

- CRUD + 批量删除
- 手机号脱敏展示
- 认证等级（未认证/实名/高级）

### 2. 企业用户 `/uas/corp`

- CRUD + 批量删除
- 统一社会信用代码唯一约束

### 3. 应用管理 `/uas/app`

- CRUD，自动生成 AppKey/Secret（UUID）

### 4. 登录日志 `/uas/log`

- 查询（按登录方式、时间范围筛选）

### 5. 认证登录

| 方式 | 接口 | 说明 |
|------|------|------|
| 管理员登录 | POST `/api/system/login` | 用户名+密码 |
| 密码登录 | POST `/api/uas/auth/password` | 手机号+密码 |
| 短信登录 | POST `/api/uas/auth/sms/send` + `/sms/login` | Redis 存验证码，RabbitMQ 异步发送 |
| 企业登录 | POST `/api/uas/auth/enterprise/corps` + `/enterprise/login` | 两步：先查企业再登录 |
| OAuth2 | GET `/api/oauth/authorize` + POST `/api/oauth/token` | 授权码模式 |

## 三、文件管理模块（DFS） 🆕

### 1. 文件基础操作

| 功能 | 接口 | 说明 |
|------|------|------|
| 上传 | POST `/api/file/upload` | 单文件，支持 MD5 秒传 |
| 批量上传 | POST `/api/file/batchUpload` | 多文件 |
| 下载 | GET `/api/file/download/{id}` | 文件流 |
| 删除 | DELETE `/api/file/{id}` | 逻辑删除 |
| 重命名 | PUT `/api/file/rename` | |
| 移动 | POST `/api/file/move` | 跨目录移动 |
| 复制 | POST `/api/file/copy` | 复制到目标目录 |
| 列表 | GET `/api/file/list` | 按目录、名称、扩展名分页查询 |
| 详情 | GET `/api/file/{id}` | |

### 2. 目录管理

| 功能 | 接口 | 说明 |
|------|------|------|
| 创建 | POST `/api/folder` | |
| 重命名 | PUT `/api/folder/rename` | |
| 删除 | DELETE `/api/folder/{id}` | 递归删除子目录及文件关联 |
| 树 | GET `/api/folder/tree` | 用户完整目录树 |
| 移动 | POST `/api/folder/move` | |
| 内容 | GET `/api/folder/content` | 列出目录下子目录+文件 |

### 3. 分享管理

| 功能 | 接口 | 说明 |
|------|------|------|
| 创建分享 | POST `/api/share` | 生成分享码(UUID)，可设密码/过期时间 |
| 访问分享 | POST `/api/share/access/{code}` | 校验密码，返回文件信息 |
| 我的分享 | GET `/api/share/list` | |
| 取消分享 | DELETE `/api/share/{id}` | |

### 4. 文件特性

- **MD5 秒传**：上传时计算 MD5，已存在则直接关联目录
- **本地存储**：文件存于 `D:\schoolTools\uploads\`，按日期分目录
- **可扩展存储**：预留 MinIO 对象存储接口，切换只需改配置

## 五、数据库表总览（20 张表）

### 原有（9 张，前缀 u_ / sys_）

| 表 | 说明 |
|-----|------|
| u_user | 自然人用户 |
| u_corp_user | 企业用户 |
| u_app | 第三方应用 |
| u_login_log | 登录日志 |
| sys_user | 系统管理员 |
| sys_role | 角色 |
| sys_menu | 菜单 |
| sys_user_role | 用户-角色关联 |
| sys_role_menu | 角色-菜单关联 |

### 新增（11 张，前缀 dfs_ / team_）

| 表 | 说明 | 核心字段 |
|-----|------|---------|
| dfs_folder | 目录 | name, parent_id, owner_id, type |
| dfs_file | 文件 | name, extension, size, md5, storage_path, bucket |
| dfs_file_folder | 文件-目录关联 | file_id, folder_id |
| dfs_file_version | 文件版本 | file_id, version_num, storage_path |
| dfs_tag | 标签 | name, color |
| dfs_file_tag | 文件-标签关联 | file_id, tag_id |
| dfs_share | 分享 | code, file_id, password, expire_time |
| team_team | 团队 | name, owner_id, max_member |
| team_member | 团队成员 | team_id, user_id, role |
| team_file | 团队文件权限 | team_id, file_id, permission |
| team_log | 团队操作日志 | team_id, user_id, action |

## 六、技术栈

| 层 | 技术 |
|----|------|
| 后端 | Spring Boot 3.2.5, Java 17 |
| ORM | MyBatis-Plus 3.5.6 |
| 权限 | Sa-Token 1.38.0 |
| 数据库 | MySQL 8.0, Redis |
| 消息队列 | RabbitMQ（短信） |
| 文件存储 | 本地磁盘（可切换 MinIO） |
| 前端 | Vue 3 + Vite 5 + Element Plus + ECharts |

## 七、启动方式

```bash
# 1. 初始化数据库
mysql -u root -p < sql/init.sql
mysql -u root -p < sql/init_dfs.sql

# 2. 启动后端（JDK 17）
cd backend
mvn spring-boot:run

# 3. 启动前端
cd frontend
npm run dev
```

访问 http://localhost:5173 ，默认管理员 admin / admin123
