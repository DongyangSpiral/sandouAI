统一认证管理（5张表）：
1. u_user — 自然人用户（手机号 UNIQUE、密码、姓名、证件号、认证等级、状态）
2. u_corp_user — 企业用户（企业名、信用代码 UNIQUE、手机号、密码）
3. u_app — 第三方应用（app_key UNIQUE、app_secret、回调地址、状态）
4. u_login_log — 登录日志（用户ID、登录方式、IP、时间）

系统管理（5张表）：
5. sys_user — 系统管理员（用户名 UNIQUE、密码、昵称、状态）
6. sys_role — 角色（角色名、角色标识、状态）
7. sys_menu — 菜单（菜单名、父菜单ID、路径、图标、排序）
8. sys_user_role — 用户角色关联（用户ID、角色ID）
9. sys_role_menu — 角色菜单关联（角色ID、菜单ID）

约束：表前缀 u_（统一认证）/ sys_（系统管理），逻辑删除 del_flag，utf8mb4，所有表有 create_time
审查的输出
检查的关键点
手机号是否有 UNIQUE 约束
密码字段是否 VARCHAR(255)（BCrypt 需要）
逻辑删除字段 is_deleted 有没有
字符集是否 utf8mb4
create_time 是否有 DEFAULT 值

短信登录
涉及的技术点
Redis 存验证码
Key: sms:手机号
Value: 6位随机数
过期: 5分钟

RabbitMQ 异步发送
短信 API 可能慢，异步发送让用户无需等待。
队列: sms.queue
